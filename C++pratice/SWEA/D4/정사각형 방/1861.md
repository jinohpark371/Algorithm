# 정사각형 방

* 링크: SWEA 1861 - 정사각형 방
* 난이도: D4
* 카테고리: DP

## 문제 요약

`N x N` 크기의 방에 1부터 `N*N`까지의 방 번호가 하나씩 적혀 있다. 어떤 방에서 상하좌우로 인접한 방 중 숫자가 1 큰 방으로만 이동할 수 있을 때, 가장 많은 방을 이어서 이동할 수 있는 출발 방 번호와 그때 이동한 방의 개수를 구하기. 답이 여러 개면 방 번호가 가장 작은 것을 출력한다.

## 핵심 아이디어

방 번호가 1부터 `N*N`까지 미리 다 주어지므로, 방 번호를 인덱스로 삼아서 그 방의 행·열 위치를 바로 찾을 수 있게 `r[번호]`, `c[번호]` 배열에 저장해둔다. 이렇게 하면 "방 번호 `v`와 `v+1`이 실제로 상하좌우로 붙어있는지"를 자리 좌표 비교 한 번으로 바로 확인할 수 있다.

```
bool adj = abs(r[v] - r[v + 1]) + abs(c[v] - c[v + 1]) == 1;
```

두 방의 행 차이와 열 차이를 절댓값으로 더한 값(맨해튼 거리)이 정확히 1이면, 둘 중 하나는 같고 나머지 하나만 1 차이난다는 뜻이므로 상하좌우로 붙어있는 것이다. 이 조건으로 "`v`에서 `v+1`로 이동할 수 있는지"를 판별한다.

여기서 핵심은, `v`에서 `v+1`로 갈 수 있다면 `v+1`에서 시작해서 이어갈 수 있는 경로는 전부 `v`에서도 그대로 이어갈 수 있다는 점이다. 즉 `v+1`에서 출발했을 때 이미 구해놓은 이동 가능 개수(`len[v+1]`)에 1만 더하면 `v`에서 출발했을 때의 이동 가능 개수가 된다(`len[v] = len[v+1] + 1`). 그래서 방 번호가 **큰 것부터 작은 것 순서**(`v = total-1`부터 `1`까지 역순)로 `len`을 채워나가면, `v+1`의 결과가 이미 구해져 있는 상태에서 `v`의 결과를 바로 이어붙여 계산할 수 있다. 붙어있지 않다면 `v`에서는 더 이상 이어갈 수 없으므로 `len[v] = 1`(자기 자신만)로 끊는다.

최댓값을 갱신할 때도 `bestLen < len[v]`가 아니라 `bestLen <= len[v]`로 비교해서, 길이가 **같을 때도** 갱신해준다. 방 번호를 큰 것부터 작은 순서로 내려가며 계산하므로, 같은 길이가 여러 번 나오면 매번 갱신되어 마지막에는 가장 작은 방 번호가 `bestRoom`에 남게 된다 — 문제에서 요구하는 "답이 여러 개면 가장 작은 방 번호"를 별도 분기 없이 비교 연산자 하나로 처리한 것이다.

## 막혔던 부분 / 실수

* 없음 — 방 번호가 1 큰 쪽으로만 이동 가능하다는 조건을 이용해, `v+1`의 결과를 먼저 구해두고 `v`가 거기에 1을 더해 이어받는 역순 DP로 풀었고, 최댓값 비교에 `<=`를 써서 동일한 최댓값 중 가장 작은 방 번호가 자연스럽게 남도록 처리

## 시간복잡도

* 시간: O(N²) (방 하나당 상수 시간 비교)
* 공간: O(N²) (`r`, `c`, `len` 배열)
