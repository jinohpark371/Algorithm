# 합성수 방정식

* 링크: SWEA 16002 - 합성수 방정식
* 난이도: D3
* 카테고리: 수학 / 완전탐색

## 문제 요약

정수 `n`이 주어질 때, `x - y = n`을 만족하면서 `x`와 `y`가 모두 합성수(1과 자기 자신 외의 약수를 가지는 수)인 `x`, `y` 쌍을 아무거나 하나 구하기. 테스트케이스 `t`개가 주어진다.

## 핵심 아이디어

`x - y`의 차이가 항상 `n`으로 유지되도록, `x`는 `2 + n`, `y`는 `2`부터 시작해서 매번 `x`와 `y`를 동시에 1씩 증가시키며 탐색한다(`x++; y++;`). 이렇게 하면 두 값 모두 증가해도 차이는 계속 `n`으로 고정된다.

`is_compositeNumber(x, y)`는 `x`와 `y`가 둘 다 합성수인지 판별한다.

* `x <= 2` 또는 `y <= 2`이면 소수/1이라 합성수가 될 수 없으므로 바로 `false`.
* `x`에 대해 `2`부터 `x - 1`까지 순회하며 나누어떨어지는 약수를 찾으면 `xIsVaild = true`로 두고 `break`로 for문을 빠져나온다. 즉, 약수가 하나라도 발견되어 합성수임이 확인되는 즉시 더 탐색하지 않고 for문을 나온다.
* `y`도 같은 방식으로 확인한다.
* 두 값이 모두 합성수(`xIsVaild && yIsVaild`)일 때만 `true`를 반환한다.

`main`의 `while (!is_compositeNumber(x, y))` 루프는 `x`, `y`가 둘 다 합성수가 되는 순간을 만날 때까지 두 값을 함께 증가시키며 탐색하고, 조건을 만족하면 루프를 빠져나와 그때의 `x`, `y`를 출력한다.

## 막혔던 부분 / 실수

* 없음 — `x - y`의 차이를 `n`으로 고정한 채 두 값을 함께 증가시키고, 합성수 판별 시 약수를 찾는 즉시 `break`로 불필요한 반복을 줄이는 방식으로 구현

## 시간복잡도

* 시간: O(T × N × X) (테스트케이스마다 조건을 만족하는 `x`를 찾을 때까지 반복하고, 매번 합성수 판별에 O(X)가 걸림)
* 공간: O(1)
