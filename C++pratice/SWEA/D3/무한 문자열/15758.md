# 무한 문자열

* 링크: SWEA 15758 - 무한 문자열
* 난이도: D3
* 카테고리: 문자열

## 문제 요약

문자열 `S`와 `T`가 주어질 때, `S`를 무한히 이어붙인 문자열(`SSSS...`)과 `T`를 무한히 이어붙인 문자열(`TTTT...`)이 서로 같은지 판별하기. 테스트케이스 `t`개가 주어진다.

## 핵심 아이디어

무한 문자열 `SSSS...`와 `TTTT...`가 완전히 같으려면, 앞부분 일부만 비교해봐도 충분하다는 성질을 이용한다. 두 무한 문자열이 같다면, 그 안에는 `S` 뒤에 `T`가 이어지는 부분과 `T` 뒤에 `S`가 이어지는 부분이 공통으로 등장할 수밖에 없다 — 즉 `S + T`와 `T + S`가 서로 같아야 한다.

반대로 `S + T == T + S`가 성립한다면, `S`와 `T`는 어떤 공통 문자열의 반복으로만 이루어질 수 있고, 그 결과 무한히 늘어놓은 `SSSS...`와 `TTTT...`도 결국 같은 패턴이 무한히 반복되는 동일한 문자열이 될 수밖에 없다. 따라서 `S + T`와 `T + S`라는 유한한 길이의 문자열 두 개만 비교하면, 무한히 늘어나는 문자열 전체가 같은지를 판별할 수 있다.

그래서 코드에서는 무한 문자열을 실제로 만들 필요 없이 `S + T == T + S` 한 번만 비교해서 "yes"/"no"를 판정한다.

## 막혔던 부분 / 실수

* 없음 — 무한 반복되는 두 문자열이 같은지를 직접 비교할 수 없으므로, "같다면 S+T와 T+S도 같아야 하고, 그 역도 성립한다"는 성질로 문제를 유한한 비교로 환원

## 시간복잡도

* 시간: O(T × (|S| + |T|)) (테스트케이스마다 문자열 결합과 비교에 선형 시간)
* 공간: O(|S| + |T|) (결합된 문자열 저장)
