# 교환학생

* 링크: SWEA 13038 - 교환학생
* 난이도: D3
* 카테고리: 구현

## 문제 요약

한 주(7일)의 각 요일마다 수업이 있는지(1) 없는지(0)가 `weeks` 배열로 주어진다. 수업을 `N`번 들어야 할 때, 어느 요일부터 시작하든 상관없이 최소 며칠이 걸리는지 구하기. 테스트케이스 `tc`개가 주어진다.

## 핵심 아이디어

요일은 7일 후 다시 처음으로 돌아오는 원형 구조라서, 배열에서 "가장 첫 번째 1"부터 시작한다고 해서 그게 최소 기간을 주는 게 아니다. 그래서 수업이 있는 요일을 전부 시작점으로 하나씩 시도해보고, 그중 걸리는 기간이 가장 적은 경우를 답으로 한다.

* 반례: `weeks = 1 0 0 0 0 0 1`, `N = 2`(인덱스 0번째와 6번째 요일에 수업이 있음).
  * 인덱스 0부터 시작하면: 0번째(1번째 수업) → 1~5번째는 빈 구간 → 6번째(2번째 수업)까지 총 7일이 걸린다.
  * 인덱스 6부터 시작하면: 6번째(1번째 수업) → 다음날 0번째(2번째 수업)까지 총 2일만에 끝난다.
  * 같은 입력인데 시작점을 어디로 잡느냐에 따라 7일과 2일로 답이 달라진다.
* 이런 차이가 생기는 이유는, 요일이 원형으로 이어져 있어서 배열 상 "처음"인 인덱스가 원형에서는 수업 사이의 빈 구간 바로 뒤에 있을 수도 있기 때문이다. 어느 인덱스에서 시작하느냐에 따라 그 빈 구간을 몇 번(또는 몇 칸) 지나게 되는지가 달라지므로, 특정 시작점 하나만으로는 최소 기간을 보장할 수 없다.
* 그래서 `weeks[start] == 1`인 모든 `start`에 대해, 그 지점부터 `(idx + 1) % 7`로 원형으로 돌면서 수업을 `N`번 채울 때까지 걸리는 날짜(`totalDays`)를 각각 계산하고, 그 값들 중 최솟값을 `answer`로 갱신한다.

## 막혔던 부분 / 실수

* 처음에는 배열에서 가장 첫 번째로 나오는 1(수업이 있는 요일)부터만 탐색을 시작하면 될 거라 생각했는데, 요일이 원형 구조이기 때문에 시작점에 따라 빈 구간을 지나는 횟수가 달라져서 최소 기간이 나오지 않는 경우가 있었다. 그래서 수업이 있는 모든 요일을 각각 시작점으로 시도해보고 그중 최솟값을 구하는 방식으로 고쳤다.

## 시간복잡도

* 시간: O(TC × 7 × (N + 7)) (최대 7개의 시작점에서 각각 수업 N번을 채울 때까지 원형 탐색)
* 공간: O(1) (요일 배열은 항상 크기 7)
