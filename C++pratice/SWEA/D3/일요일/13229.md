# 일요일

* 링크: SWEA 13229 - 일요일
* 난이도: D3
* 카테고리: 구현

## 문제 요약

오늘의 요일(`SUN`, `MON`, ..., `SAT`)이 문자열로 주어질 때, 다음 일요일까지 남은 날짜 수를 구하기. 테스트케이스 `tc`개가 주어진다.

## 핵심 아이디어

`weeks` 배열에 `SUN`을 맨 앞(인덱스 0)에 두고 나머지 요일을 순서대로 배치해두면, 각 요일의 인덱스가 "지난 일요일로부터 며칠이 지났는지"를 그대로 나타내게 된다. 그래서 `7 - idx`로 다음 일요일까지 남은 날짜를 바로 계산할 수 있다.

* 입력받은 `day` 문자열을 `weeks` 배열에서 순서대로 찾아, 일치하는 인덱스 `idx`를 구한다(`SUN`이면 0, `MON`이면 1, ..., `SAT`이면 6).
* 한 주는 7일이므로, 지난 일요일로부터 `idx`일이 지난 오늘부터 다음 일요일까지는 `7 - idx`일이 남는다.

## 막혔던 부분 / 실수

* 없음 — 요일 배열의 시작점을 일요일로 맞춰두면 인덱스 자체가 "일요일로부터 지난 일수"가 되므로, 별도의 요일 간 거리 계산 없이 `7 - idx` 한 줄로 바로 답이 나옴

## 시간복잡도

* 시간: O(TC) (요일 비교는 상수 7번)
* 공간: O(1)
