# 구구단 걷기

* 링크: SWEA 16800 - 구구단 걷기
* 난이도: D3
* 카테고리: 수학 / 완전탐색

## 문제 요약

정수 `n`이 주어질 때, `j * r = n`을 만족하는 약수 쌍 `(j, r)` 중에서 `(j - 1) + (r - 1)`(가로/세로로 이동해야 하는 값의 합)이 최소가 되는 값을 구하기. 테스트케이스 `t`개가 주어진다.

## 핵심 아이디어

`n`의 약수는 항상 `j * r = n`을 만족하는 쌍으로 존재하고, 이 쌍은 `n`의 제곱근을 기준으로 작은 쪽 `j`와 큰 쪽 `r`로 나뉜다. 그래서 `j`를 1부터 시작해 `j * j <= n`(즉 `j`가 제곱근 이하)인 범위까지만 탐색하면, 그 짝인 `r = n / j`는 자동으로 제곱근 이상이 되어 모든 약수 쌍을 중복 없이 한 번씩만 확인할 수 있다.

각 약수 쌍마다 이동값 `(j - 1) + (r - 1)`을 계산해 `ans`를 최솟값으로 갱신한다. `j`가 제곱근에 가까울수록(즉 `j`와 `r`이 서로 비슷한 크기일수록) 이 합이 작아지므로, 제곱근 근처의 약수 쌍이 곧 최적해에 가깝다는 것을 완전탐색으로 확인하는 구조.

## 막혔던 부분 / 실수

* `n`과 `ans`를 `int`로 선언했다가 오버플로우 발생 — `n`의 범위가 커서 `j * j`나 `n / j` 같은 계산 및 `ans` 누적값이 `int` 범위를 넘어설 수 있었음. `long long`으로 바꾸고 `ans`의 초기값도 `INT_MAX` 대신 `LLONG_MAX`로 수정해서 해결

## 시간복잡도

* 시간: O(T × √N) (테스트케이스마다 제곱근까지만 약수 탐색)
* 공간: O(1)
