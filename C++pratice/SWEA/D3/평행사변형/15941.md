# 평행사변형

* 링크: SWEA 15941 - 평행사변형
* 난이도: D3
* 카테고리: 수학

## 문제 요약

네 변의 길이가 모두 `n`으로 같은 평행사변형이 있을 때, 만들 수 있는 최대 넓이를 구하기. 테스트케이스 `t`개가 주어진다.

## 핵심 아이디어

네 변의 길이가 모두 `n`으로 같은 평행사변형의 넓이는 `n * n * sin(θ)` (θ는 두 변 사이의 각)로 계산되고, `sin(θ)`는 θ가 90도일 때 최댓값 1을 가진다. 즉 각을 직각으로 만들었을 때, 다시 말해 정사각형이 되었을 때 넓이가 최대가 된다.

따라서 넓이를 직접 삼각함수로 구할 필요 없이, 변의 길이가 `n`인 정사각형의 넓이 `n * n`이 바로 최대 넓이가 된다.

## 막혔던 부분 / 실수

* 없음 — 평행사변형의 넓이가 낀각의 sin값에 비례한다는 점에서, 넓이가 최대가 되는 경우가 정사각형(각 90도)임을 파악하면 별도의 탐색 없이 `n * n`으로 바로 계산 가능

## 시간복잡도

* 시간: O(T) (테스트케이스마다 상수 시간 계산)
* 공간: O(1)
