# 알파벳 공부

* 링크: SWEA 15230 - 알파벳 공부
* 난이도: D3
* 카테고리: 문자열

## 문제 요약

문자열이 주어질 때, 앞에서부터 `a, b, c, ...` 알파벳 순서대로 몇 글자까지 맞게 이어지는지 구하기. 테스트케이스 `tc`개가 주어진다.

## 핵심 아이디어

알파벳 순서(`"abcdefghijklmnopqrstuvwxyz"`)를 미리 문자열 `s`로 만들어두면, 입력 문자열의 `i`번째 글자가 알파벳의 `i`번째 글자(`s[i]`)와 같은지만 확인하면 "순서대로 맞게 이어지는지"를 바로 판별할 수 있다. 문제에서 요구하는 건 단순히 각 위치에 어떤 알파벳이 오든 상관없는 게 아니라, 반드시 `a, b, c, ...` 순서 그대로 맞아야 하는 것이므로, 글자가 위치상 알파벳과 같은지가 아니라 순서 자체가 끊기지 않고 이어지는지를 봐야 한다.

* `input[i]`가 `s[i]`와 같으면 아직 순서가 안 끊긴 것이므로 `cnt`를 늘리고 계속 진행한다.
* 한 번이라도 `input[i] != s[i]`이면, 그 지점에서 순서가 어긋난 것이므로 더 뒤를 볼 필요 없이 바로 `break`로 반복을 멈춘다. 뒤에 우연히 다시 알파벳 순서와 맞는 글자가 나오더라도 중간에 한 번 끊겼다면 그건 이미 "순서대로 이어진 것"이 아니기 때문이다.

이렇게 하면 `cnt`에는 처음부터 끊기지 않고 알파벳 순서와 일치한 글자 수만 남게 된다.

## 막혔던 부분 / 실수

* 없음 — 각 글자가 알파벳 중 어느 글자와 같은지가 아니라, 반드시 `a`부터 순서대로 끊기지 않고 이어지는지를 봐야 하므로 한 번이라도 어긋나면 바로 `break`해서 더 진행하지 않도록 처리

## 시간복잡도

* 시간: O(TC × L) (테스트케이스마다 입력 문자열 길이만큼 순회)
* 공간: O(1)
