# XOR 2차원 배열

* 링크: SWEA 15868 - XOR 2차원 배열
* 난이도: D3
* 카테고리: 수학 / 완전탐색

## 문제 요약

`n x m` 크기의 0/1 배열 `T`가 주어졌을 때, `T[i][j] = a[i] ^ b[j]`를 만족하는 배열 `a`(길이 n), `b`(길이 m)가 존재하는지 판별하기. 존재하면 "yes", 존재하지 않으면 "no"를 출력한다.

## 핵심 아이디어

**관찰 1**: `T[i][j] = a[i] ^ b[j]`가 성립한다면, `a[0]`(첫 번째 행 기준값) 하나만 알아도 나머지 `a`, `b` 값이 전부 연쇄적으로 결정된다.

* 첫 번째 행에서: `b[j] = T[0][j] ^ a[0]`
* 첫 번째 열에서: `a[i] = T[i][0] ^ b[0]`

**관찰 2**: `a[0]`은 0일 수도 1일 수도 있지만, `a` 전체를 반전시키고 `b` 전체도 함께 반전시키면 `a[i] ^ b[j]` 값은 그대로 유지된다(비트가 둘 다 뒤집히면 XOR 결과는 안 변함). 따라서 `a[0] = 0`으로 고정해도 일반성을 잃지 않으며, 0/1 두 경우를 모두 시도해볼 필요가 없다.

**전체 흐름**:

1. `a[0] = 0`으로 고정
2. 첫 번째 행(`T[0][j]`)으로부터 `b[0], ..., b[m-1]` 전부 유도
3. 첫 번째 열(`T[i][0]`)로부터 `a[0], ..., a[n-1]` 전부 유도 (이때 `a[0]`은 이미 0으로 고정했으므로, 유도된 값이 실제로 0이 되는지도 검증 역할을 겸함)
4. 유도된 `a`, `b`로 `a[i] ^ b[j]`를 전부 다시 계산해서 원본 `T`와 모든 칸이 일치하는지 전수 검증
5. 하나라도 불일치하면 "no", 모두 일치하면 "yes" 출력

즉 후보를 여러 개 탐색하는 게 아니라, 관찰 2 덕분에 후보가 단 하나로 줄어들고 그 하나를 검증만 하면 되는 구조.

## 막혔던 부분 / 실수

* 없음 — `a[0]`을 임의로 두 가지 다 시도해야 할 것 같지만, `a`와 `b`를 동시에 반전해도 XOR 결과가 불변한다는 성질을 이용해 `a[0] = 0`으로 고정한 뒤 한 번만 유도·검증하면 충분함을 파악

## 시간복잡도

* 시간: O(T × N × M) (테스트케이스마다 `a`, `b` 유도는 O(N+M), 전수 검증은 O(N×M))
* 공간: O(N + M) (`a`, `b` 배열) + O(N × M) (`T` 저장)
