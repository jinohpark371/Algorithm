# 통나무 자르기

* 링크: SWEA 14692 - 통나무 자르기
* 난이도: D3
* 카테고리: 게임 이론

## 문제 요약

길이가 `N`인 통나무를 Alice와 Bob이 번갈아가며 정수 길이로 자르는 게임이다. 자기 턴에 더 이상 자를 수 없는(길이가 1이 되어버린) 사람이 지며, Alice가 먼저 시작한다. 최종 승자를 구하기. 테스트케이스 `tc`개가 주어진다.

## 핵심 아이디어

통나무는 자를 때마다 조각 하나가 1이상인 두 조각으로 나뉘는데, 결국 모든 조각이 길이 1이 될 때까지 자르는 행위를 반복하게 되고, 길이 `N`짜리 통나무를 전부 길이 1로 쪼개는 데 필요한 총 자르는 횟수는 항상 `N - 1`번으로 고정된다(누가 어떻게 자르든 상관없이).

* 자르는 순서가 Alice → Bob → Alice → ... 순서로 번갈아 진행되므로, 총 `N - 1`번의 턴 중 홀수 번째 턴(1번째, 3번째, ...)은 Alice가, 짝수 번째 턴은 Bob이 자르게 된다.
* 마지막으로 자르는 사람(= `N - 1`번째 턴을 가져가는 사람)이 이기는 쪽이다. 더 이상 자를 수 없는 상태(길이 1만 남음)를 맞이한 쪽이 지는 것이므로, 그 직전까지 자르기를 성공적으로 수행한 쪽이 승자가 된다.
* 따라서 `N - 1`이 홀수면 마지막 자르기가 Alice의 턴이므로 Alice 승, 짝수면 Bob 승이다. 즉 `(N - 1) % 2 == 1`이면 Alice, 아니면 Bob.

## 막혔던 부분 / 실수

* 없음 — 통나무를 전부 길이 1로 자르는 데 필요한 총 횟수가 항상 `N - 1`번으로 고정된다는 점을 이용해, 누가 어떤 식으로 잘랐는지는 따질 필요 없이 `N - 1`의 홀짝만으로 마지막 자르기를 가져가는(=승리하는) 사람을 바로 판별

## 시간복잡도

* 시간: O(TC)
* 공간: O(1)
