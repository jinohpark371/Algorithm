# 상호의 배틀필드

* 링크: SWEA 1873 - 상호의 배틀필드
* 난이도: D3
* 카테고리: 구현 / 시뮬레이션

## 문제 요약

`H x W` 크기의 맵에 평지(`.`), 벽돌 벽(`*`), 강철 벽(`#`), 물(`-`)과 전차 1대(`^`, `v`, `<`, `>` 중 하나, 바라보는 방향)가 있다. 명령 문자열이 주어지는데, `U`/`D`/`L`/`R`은 전차가 그 방향을 바라보게 바꾸고 다음 칸이 평지면 한 칸 이동하는 명령이고, `S`는 바라보는 방향으로 포탄을 쏘는 명령이다. 포탄은 벽돌 벽에 맞으면 그 벽을 평지로 부수고, 강철 벽에 맞거나 맵 밖으로 나가면 사라진다. 모든 명령을 수행한 뒤의 맵을 출력하기.

## 핵심 아이디어

전차 모양 4가지, 이동 명령 4가지마다 `switch`나 `if`문을 따로 쓰면 비슷한 코드가 방향 개수만큼 반복되어 너무 길어진다. 그래서 **방향 벡터와 인덱스를 맞춘 두 문자열**을 만들어서, 문자를 방향 번호로 바꾸는 작업을 `find` 한 번으로 처리한다.

```cpp
int dr[4] = {-1, 1, 0, 0};
int dc[4] = {0, 0, -1, 1};
string shape = "^v<>";
string cmdChar = "UDLR";
```

* 인덱스 0은 위, 1은 아래, 2는 왼쪽, 3은 오른쪽으로 네 배열/문자열 모두 같은 순서를 쓴다. 그래서 `shape[d]`, `cmdChar[d]`, `(dr[d], dc[d])`가 항상 같은 방향을 가리킨다.
* **이동 명령(`U`/`D`/`L`/`R`)**: `d = cmdChar.find(cmd)`로 명령 문자가 몇 번 방향인지 구한다. 다음 칸 `(r + dr[d], c + dc[d])`가 맵 안이고 평지(`.`)면 원래 칸을 `.`으로 바꾸고 전차를 이동시킨다. 이동하지 못하더라도 방향은 바뀌어야 하므로, 마지막에 항상 `board[r][c] = shape[d]`로 전차 모양을 그 방향으로 바꾼다.
* **포탄 발사(`S`)**: 현재 전차 모양으로 방향을 알아내야 하므로 `d = shape.find(board[r][c])`로 방향 번호를 구한다. 그 방향으로 `dr[d]`, `dc[d]`만큼 계속 전진하면서 강철 벽(`#`)이면 멈추고, 벽돌 벽(`*`)이면 `.`으로 부수고 멈춘다. 맵 밖으로 나가면 반복문 조건에서 자연스럽게 끝난다.
* 처음 전차 위치는 각 줄을 입력받을 때 `s.find_first_of("^v<>")`로 전차 문자가 있는 열을 찾아서 `(r, c)`에 저장해 둔다.

결국 "문자 → 방향 번호" 변환만 문자열의 위치로 해결하면, 이동과 발사 로직은 방향 하나에 대해서만 작성해도 네 방향 모두에 그대로 적용된다.

## 시간복잡도

* 시간: O(N × max(H, W)) (명령마다 이동은 O(1), 포탄은 최대 한 줄 길이만큼 전진)
* 공간: O(H × W) (`board`)
