# 체스판 위의 룩 배치

* 링크: SWEA 15612 - 체스판 위의 룩 배치
* 난이도: D3
* 카테고리: 구현

## 문제 요약

8×8 체스판에 룩이 있는 칸은 `O`, 빈 칸은 `.`으로 주어질 때, 룩이 정확히 8개 있고 어떤 두 룩도 서로 공격할 수 없는지(같은 행이나 같은 열에 두 개 이상 없는지) 판별하기. 조건을 만족하면 "yes", 아니면 "no"를 출력한다. 테스트케이스 `t`개가 주어진다.

## 핵심 아이디어

룩은 같은 행 또는 같은 열에 있는 말을 공격할 수 있으므로, 유효한 배치라면 각 행과 각 열에 룩이 최대 하나씩만 있어야 한다.

이를 확인하기 위해 행 사용 여부를 기록하는 `rows` 벡터와 열 사용 여부를 기록하는 `cols` 벡터(크기 8, 초기값 `false`)를 둔다. 체스판을 순회하다가 룩(`O`)이 나오면

* 해당 행 `rows[i]`와 열 `cols[j]`이 모두 아직 사용되지 않았다면 → 둘 다 `true`로 체크하고 룩 개수 `cnt`를 1 증가
* 둘 중 하나라도 이미 사용되었다면 → 같은 행/열에 룩이 두 개 있다는 뜻이므로 유효하지 않음으로 판단하고 순회를 종료

순회가 끝난 뒤에는 충돌이 없었는지와 함께 룩이 정확히 8개인지(`cnt == 8`)도 확인한다. 충돌이 없더라도 룩이 8개보다 적으면 조건을 만족하지 않으므로, 두 조건을 모두 만족할 때만 "yes"를 출력한다.

## 막혔던 부분 / 실수

* 없음 — 행/열 충돌 검사만으로는 룩 개수가 부족한 경우를 걸러낼 수 없으므로, 룩 개수가 8개인지 별도로 확인

## 시간복잡도

* 시간: O(T × 64) (테스트케이스마다 8×8 칸을 한 번씩 순회)
* 공간: O(1) (고정 크기의 체스판과 행/열 체크 벡터)
