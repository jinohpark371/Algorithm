# 부분 수열의 합

* 링크: SWEA 2817 - 부분 수열의 합
* 난이도: D3
* 카테고리: DFS / 완전탐색

## 문제 요약

`N`개의 숫자가 주어질 때, 그중 일부를 골라 만든 부분 수열(순서를 유지하는 부분집합)의 합이 `K`가 되는 경우의 수를 구하기. 테스트케이스 `tc`개가 주어진다.

## 핵심 아이디어

모든 부분집합을 다 만들어보면서 합이 `K`인 경우를 세는 완전탐색이다. `DFS(st, cur)`는 "지금까지 고른 숫자들의 합이 `cur`"이라는 상태를 나타내며, `st`는 "이번에 새로 고를 숫자는 인덱스 `st`부터 본다"는 뜻이다.

* 함수에 들어오면 먼저 `cur == K`인지 확인해서, 맞으면 `cnt`를 늘린다. 여기서 바로 `return`하지 않는 이유는, 지금까지 고른 숫자들만으로 이미 합이 `K`가 됐더라도 그 뒤에 더 숫자를 추가해서 또 다른 조합(합이 다시 달라지는 경우)을 계속 만들어볼 수 있기 때문이다. 즉 "합이 K인 부분집합 하나를 찾았다"는 것과 "더 이상 탐색할 필요가 없다"는 건 다른 얘기다.
* `st`부터 `N-1`까지의 인덱스 `i`를 순회하면서, `nums[i]`를 현재 부분집합에 포함시켜본다(`cur += nums[i]`), 그 상태로 재귀(`DFS(i + 1, cur)`)를 호출해서 그다음 숫자부터 또 고를지 말지를 계속 탐색하고, 재귀가 끝나면 `cur -= nums[i]`로 되돌려서 이 숫자를 포함하지 않은 경우도 이어서 탐색할 수 있게 백트래킹한다.
* 재귀 호출 시 시작 인덱스를 항상 `i + 1`(현재 선택한 인덱스보다 뒤)로 넘기기 때문에, 같은 숫자를 두 번 쓰거나 순서를 거슬러 고르는 일 없이 모든 부분집합을 중복 없이 한 번씩만 만들어본다.

## 막혔던 부분 / 실수

* 없음 — `cur == K`를 확인한 뒤에도 재귀를 계속 진행해야(바로 종료하지 않아야) 그 뒤에 이어지는 다른 부분집합들도 전부 탐색된다는 점과, 시작 인덱스를 `i + 1`로 넘겨서 중복 선택 없이 모든 부분집합을 만드는 표준적인 패턴을 사용

## 시간복잡도

* 시간: O(TC × 2^N) (모든 부분집합의 수가 2^N개)
* 공간: O(N) (재귀 깊이)
