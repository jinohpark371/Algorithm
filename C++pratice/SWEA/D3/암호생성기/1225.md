# 암호생성기

* 링크: SWEA 1225 - 암호생성기
* 난이도: D3
* 카테고리: 구현 / 큐

## 문제 요약

8개의 숫자가 주어질 때, 첫 번째 숫자에서 1을 빼고 맨 뒤로 보내고, 다음 첫 번째 숫자에서 2를 빼고 맨 뒤로 보내는 식으로 1~5를 차례로 빼는 과정(한 사이클)을 반복한다. 숫자가 감소하다가 0보다 작거나 같아지면 0으로 맞춰 맨 뒤로 보내고 프로그램을 종료한다. 이때의 8개 숫자가 암호가 된다. 테스트케이스 10개가 주어진다.

## 핵심 아이디어

"맨 앞의 숫자를 꺼내서 값을 바꾼 뒤 맨 뒤로 보낸다"는 동작이 그대로 큐의 `pop` + `push`이기 때문에, 8개 숫자를 `queue<int>`에 넣고 시뮬레이션한다.

* 매 단계마다 `q.front()`로 맨 앞 숫자를 꺼내고 `q.pop()`으로 큐에서 삭제한다.
* 꺼낸 숫자에서 사이클 값(`cycle`)만큼 빼고 `q.push()`로 큐의 맨 뒤로 보낸다.
* 사이클 값은 1, 2, 3, 4, 5, 1, 2, ... 처럼 1~5 사이를 반복해야 하므로 `cycle = cycle % 5 + 1`로 갱신한다. `cycle`을 0으로 시작하면 첫 단계에서 1이 되고, 5 다음에는 `5 % 5 + 1 = 1`로 다시 돌아온다. 그래서 별도의 `if (cycle > 5)` 분기 없이 mod 연산 하나로 1~5 범위를 유지할 수 있다.
* 뺀 값이 0보다 작거나 같으면(`top - cycle <= 0`) 음수를 그대로 넣지 않고 0을 큐에 넣은 뒤 바로 반복을 종료한다. 0이 들어간 순간 맨 뒤가 0인 상태가 되므로 큐에 남은 순서 그대로가 정답이다.
* 마지막으로 큐가 빌 때까지 앞에서부터 꺼내며 출력한다.

## 시간복잡도

* 시간: O(10 × K) (K는 0이 나올 때까지 반복한 횟수로, 매 단계 평균 3씩 줄어드므로 입력 숫자의 크기에 비례한다. 큐 연산 자체는 O(1))
* 공간: O(8) (크기 8짜리 큐)
