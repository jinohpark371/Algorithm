# 파리 퇴치

* 링크: SWEA 2001 - 파리 퇴치
* 난이도: D2
* 카테고리: 브루트포스

## 문제 요약

`N x N` 크기의 보드에 각 칸마다 파리 수가 적혀 있을 때, `M x M` 크기의 파리채로 한 번에 잡을 수 있는 파리 수의 최댓값을 구하기. 파리채는 보드 위의 모든 위치에 올려볼 수 있다.

## 핵심 아이디어

파리채의 좌상단 좌표 `(i, j)`를 보드의 모든 위치로 옮겨가며, 그 위치에서 `M x M` 넓이만큼의 파리 수 합(`current_area`)을 직접 더해서 구하고, 지금까지 나온 값 중 최댓값(`max_area`)을 갱신해 나간다.

단, 좌상단 좌표 `(i, j)`를 아무 위치나 다 돌리면 안 된다. 파리채가 `M x M` 크기이기 때문에 좌상단이 `(i, j)`일 때 실제로 덮는 영역은 `행 i ~ i+M-1`, `열 j ~ j+M-1`까지인데, 이게 보드를 벗어나지 않으려면 `i + M - 1 <= N - 1`, 즉 `i <= N - M`이어야 한다. 그래서 좌상단 좌표의 전체 탐색 범위를 `0 <= i, j <= N - M`까지로 제한해서, 파리채가 보드 밖으로 나가는 경우를 처음부터 만들지 않는다.

## 막혔던 부분 / 실수

* 좌상단 좌표를 `N-1`까지 다 돌리면 파리채가 보드 범위를 벗어나는 경우가 생긴다는 점 → 파리채 크기 `M`을 고려해서 탐색 범위를 `N - M`까지로 줄여야 한다는 걸 확인하고 수정.

## 시간복잡도

* 시간: O(T × (N-M+1)² × M²) (좌상단 위치마다 M×M 영역의 합을 직접 계산)
* 공간: O(N²) (`board` 배열)
