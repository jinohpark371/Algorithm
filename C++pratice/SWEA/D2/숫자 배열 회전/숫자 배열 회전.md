# 숫자 배열 회전

* 링크: SWEA 1961 - 숫자 배열 회전
* 난이도: D2
* 카테고리: 구현

## 문제 요약

`N x N` 크기의 문자 배열을 시계방향으로 90도, 180도, 270도 회전시킨 결과를 각각 구해서, 각 행마다 세 결과를 나란히 출력하기. 테스트케이스가 여러 개 주어진다.

## 핵심 아이디어

90도 회전 한 번은 "각 열을 마지막 행부터 거슬러 읽어서, 그 값을 새 배열의 0번째 행부터 순서대로 채워 넣는 것"과 같다. 즉 열 `i`를 고정하고 `row[N-1][i], row[N-2][i], ..., row[0][i]` 순서로 읽은 값을 새 배열의 `i`번째 행에 앞에서부터 채우면 그게 90도 회전 결과가 된다.

원본 배열은 보존해야 하므로(180도, 270도도 결국 90도 회전을 반복 적용해서 구해야 함), 회전 대상인 `row`와 회전 결과를 담을 `rotated` 두 개의 2차원 벡터를 따로 둔다. 한 번 회전시킬 때마다 `rotated`에 결과를 채운 뒤 `row = rotated`로 두 벡터를 같은 상태로 맞춰놓고, 그 `row`를 다시 다음 회전의 입력으로 사용한다. 이렇게 하면 같은 `rotate_90` 함수를 세 번 호출해서 90도 → 180도 → 270도 결과를 순서대로 얻을 수 있다.

출력은 각 행마다 "90도 결과 행 / 180도 결과 행 / 270도 결과 행"을 한 줄에 나란히 찍어야 하는데, 회전은 한 번에 하나씩 끝나기 때문에 회전할 때마다 바로 출력할 수 없다. 그래서 90도, 180도, 270도 회전 결과를 각각 `rot_90`, `rot_180`, `rot_270`이라는 별도 벡터에 중간 저장해두고, 세 번의 회전이 모두 끝난 다음에 행 번호를 기준으로 세 벡터를 한 줄씩 묶어서 출력한다.

## 막혔던 부분 / 실수

* 회전 결과를 바로바로 출력하면 "90/180/270도를 한 줄에 나란히" 출력하는 형식을 맞출 수 없다는 걸 깨달음 → 회전 결과를 `rot_90`, `rot_180`, `rot_270`으로 각각 저장해두고 전부 회전이 끝난 뒤에 한꺼번에 출력하도록 수정

## 시간복잡도

* 시간: O(T × N²) (테스트케이스마다 회전 3번, 회전 한 번에 N×N칸을 한 번씩 읽고 씀)
* 공간: O(N²) (`row`, `rotated`, `rot_90`, `rot_180`, `rot_270` 벡터)
