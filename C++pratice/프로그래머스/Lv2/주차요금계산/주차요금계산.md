# 주차 요금 계산

* 링크: 프로그래머스 - 주차 요금 계산 (Lv.2)
* 난이도: Lv.2
* 카테고리: 해시

## 문제 요약

주차장의 기본 시간/기본 요금, 단위 시간/단위 요금이 주어지고, 차량들의 입/출차 시각이 기록된 로그(`records`)가 분 단위 오름차순으로 주어진다. 각 차량이 실제로 주차장에 머문 총 시간을 계산해서, 요금표에 따라 차량 번호 오름차순으로 지불해야 할 금액을 구하기. 영업 종료 시각(23:59)까지 출차 기록이 없는 차량은 그 시각에 출차한 것으로 간주한다.

## 핵심 아이디어

맵 세 개를 역할별로 나눠서 운용한다.

* `In`: 현재 입차해 있는 차량 번호 → 입차 시각(분) 기록용
* `period`: 차량 번호 → 지금까지 누적된 "머문 시간"(분) 기록용
* `price`: 차량 번호 → 최종 요금 기록용

### 1단계 — 전체 차량의 머문 기간 계산

`records`를 순서대로 순회하면서,

* `IN`이면 그 차량의 입차 시각을 `In`에 저장한다.
* `OUT`이면 `(출차 시각 - In[차량번호])`를 `period`에 누적(`+=`)하고, `In`에서 그 차량을 지운다. 같은 차량이 입/출차를 여러 번 반복해도 `period`에 계속 더해지므로 자연스럽게 전체 머문 시간이 합산된다.

모든 로그를 다 처리한 뒤에도 `In`에 남아있는 차량은 출차 기록 없이 영업 종료까지 주차장에 있던 차량이므로, `(23*60+59) - In[차량번호]`를 마지막으로 `period`에 한 번 더 누적해준다.

### 2단계 — 요금 계산

`period`에 차량별 총 머문 시간이 다 모이면, 그걸 기준으로 요금을 계산한다. `fees = [기본시간, 기본요금, 단위시간, 단위요금]`일 때,

* 머문 시간이 기본 시간 이하면 기본 요금만 부과.
* 기본 시간을 초과하면 `기본요금 + ceil((머문시간 - 기본시간) / 단위시간) * 단위요금`.
  * 올림 계산은 정수 나눗셈만으로 표현해야 하므로, 초과 시간이 1분이라도 남으면 단위 시간 하나를 더 적용해야 한다는 뜻에서 `(초과시간 + (단위시간 - 1)) / 단위시간` 형태로 "나누기 전에 분자를 단위시간-1만큼 밀어 올리는" 트릭을 사용한다.

### 3단계 — 결과 정리

`map`은 기본적으로 key(차량 번호 문자열) 기준 오름차순으로 정렬돼 있으므로, `price`를 그대로 순회하며 값만 뽑아 `answer`에 넣으면 별도의 정렬 없이 차량 번호 오름차순 결과를 얻는다.

## 막혔던 부분 / 실수

* 영업 종료까지 출차하지 않은 차량(`In`에 남아있는 차량)도 머문 시간 계산에 포함해야 한다는 점 — 전체 로그 처리가 끝난 뒤 `In`에 남은 차량들을 별도로 순회하며 23:59 기준으로 한 번 더 `period`에 누적해서 처리.
* 초과 시간에 대한 올림 계산을 정수 연산으로 표현할 때 `(초과시간 + 단위시간 - 1) / 단위시간` 트릭이 필요하다는 점.

## 시간복잡도

* 시간: O(R log R) (R = `records.size()`, 맵 삽입/탐색/삭제가 각각 O(log R))
* 공간: O(C) (C = 차량 수, `In`/`period`/`price` 맵)
