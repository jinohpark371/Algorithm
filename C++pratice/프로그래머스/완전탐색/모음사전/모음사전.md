# 모음사전

* 링크: 프로그래머스 - 모음사전 (Lv.2)
* 난이도: Lv.2
* 카테고리: 완전탐색

## 문제 요약

알파벳 모음 'A', 'E', 'I', 'O', 'U' 만으로 만들 수 있는 길이 1~5 사이의 모든 문자열을 사전 순으로 나열했을 때, 주어진 단어가 몇 번째 순서에 있는지 구하기.

## 핵심 아이디어

재귀(DFS)로 한 글자씩 선택해 문자열을 늘려가며 모든 경우를 만든다. 각 재귀 호출마다 `cnt`를 하나씩 증가시켜 "지금까지 만들어진 문자열이 몇 번째인지"를 센다. 매 자리에서 'A' → 'E' → 'I' → 'O' → 'U' 순서로 마지막 글자를 하나씩 바꿔가며 다음 글자를 채워나가면, 트리를 왼쪽부터 순서대로 훑는 것과 같아져 자연스럽게 사전 순으로 모든 문자열이 만들어진다.

현재까지 만든 문자열(`cur`)이 찾는 단어(`copied_word`)와 같아지는 순간 `found`를 true로 세팅하고 `answer`에 그때의 `cnt`를 저장한다. 이후 재귀 호출들이 `found`를 확인해서 바로 `return` 하기 때문에, 정답을 찾은 지점보다 더 깊이 들어가거나 남은 형제 분기(다음 모음들)를 더 이상 탐색하지 않는다. 즉 완전탐색 트리 전체를 다 돌지 않고, 정답을 찾는 즉시 재귀 스택을 타고 올라오며 탐색을 종료하는 가지치기 역할을 `found`가 담당한다.

## 막혔던 부분 / 실수

* 처음엔 모든 경우의 수를 다 만들고 나서 비교하려고 했는데, 정답을 찾은 이후에도 재귀가 계속 깊이 들어가거나 다른 분기를 도는 게 비효율적이라는 걸 깨달음 → `found` 플래그를 두고 재귀 진입/종료 시점마다 체크해서 더 깊이 들어가지 않고 바로 return 하도록 수정

## 시간복잡도

* 시간: O(5^1 + 5^2 + ... + 5^5) = O(1) (문자열 길이가 최대 5로 고정되어 있어 상수 시간)
* 공간: O(1) (재귀 깊이가 최대 5)
