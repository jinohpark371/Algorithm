# 카펫

* 링크: 프로그래머스 - 카펫 (Lv.1)
* 난이도: Lv.1
* 카테고리: 완전탐색

## 문제 요약

갈색 테두리와 노란색 안쪽으로 이루어진 격자 카펫이 있다. 갈색 격자 수와 노란색 격자 수가 주어졌을 때, 카펫의 가로(w)와 세로(h) 크기를 구하기 (단, 가로가 세로보다 크거나 같음).

## 핵심 아이디어

전체 넓이는 `total = brown + yellow`. w는 전체 넓이의 제곱근보다 크거나 같은 값부터 시작해야 하므로 `w * w >= total`을 만족하는 지점부터 h를 탐색한다. h는 테두리(갈색)가 만들어지려면 최소 3은 되어야 하므로 3부터 시작하고, 문제 조건상 `h <= w`이므로 `h > w`가 되면 더 탐색할 필요 없이 break.

갈색 넓이는 전체 바깥 넓이에서 안쪽 노란색 넓이를 뺀 값이므로 `w * h - (w - 2) * (h - 2)`로 계산할 수 있다. 이 값이 주어진 `brown`과 같은 (w, h)를 찾으면 정답이므로, `answer`에 담고 `isStop`을 참으로 바꿔 바깥 for문까지 모두 탈출한다.

## 막혔던 부분 / 실수

* 없음 — w의 탐색 시작 조건(제곱근 이상)과 h의 시작 조건(최소 3), `h <= w` 제약을 이용해 탐색 범위를 좁히고, 조건을 만족하면 `isStop` 플래그로 이중 for문을 한 번에 탈출

## 시간복잡도

* 시간: O(√total × √total) 수준 (w, h 탐색 범위가 총 넓이의 제곱근 근처로 제한됨)
* 공간: O(1)
