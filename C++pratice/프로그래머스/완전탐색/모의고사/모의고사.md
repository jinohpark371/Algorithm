# 모의고사

* 링크: 프로그래머스 - 모의고사 (Lv.1)
* 난이도: Lv.1
* 카테고리: 완전탐색

## 문제 요약

수포자 1, 2, 3은 각자 정해진 패턴을 반복해서 찍는다. 실제 정답 배열이 주어졌을 때, 가장 많은 문제를 맞힌 사람(들)의 번호를 배열로 반환한다. 여러 명이 동점으로 최다 정답이면 번호가 낮은 순서대로 모두 반환한다.

## 핵심 아이디어

각 수포자의 찍기 패턴을 배열로 미리 정의해두고, 정답 배열을 순회하면서 각자의 패턴을 인덱스를 `% 패턴 길이`로 순환시켜가며 몇 문제를 맞혔는지 카운팅한다. 한 번의 순회로 세 명의 정답 개수를 동시에 구할 수 있다.

카운팅이 끝나면 (맞힌 개수, 번호) 쌍을 만들어 정렬하고, 그중 최댓값과 같은 개수를 가진 사람만 번호 순서대로 답에 담는다.

## 막혔던 부분 / 실수

* 없음 — 패턴별 인덱스를 각각 따로 순환시키는 방식으로 한 번에 처리

## 시간복잡도

* 시간: O(n)
* 공간: O(1) (패턴 배열 크기는 고정)
